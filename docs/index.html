llama.cpp Decision Models

Web UI for Decision Models in llama.cpp: send a state plus typed questions (choice / score / noul) to POST /v1/systemone and see option probabilities as bars.

  • Mock mode is on by default (keyword heuristics, clearly labelled), so it runs without a GPU or server
  • Point it at a real server, e.g. Julia-1 (144M, Apache-2.0) via llama serve
cd apps/llamacpp-decision-models
bun install && bun run dev

EmbeddingGemma 2

Semantic search with google/embeddinggemma-2: text to 768-d cosine similarity over a tiny local corpus, with a FastAPI server and a Vite UI that ranks matches with scores.

  • Loads the model text-only through Sentence Transformers (vision and audio encoders dropped)
  • If the model can't download, it falls back to a hash embedder that the UI labels MOCK
cd apps/embeddinggemma-2
pip install -r requirements.txt
python server/app.py

JEPA-Anything

Kit for Gen-Verse/JEPA-Anything (arXiv:2609.20800), domain-agnostic predictive world models via Orthogonal Predictive Factorization. Ships a Colab notebook plus local scripts, not a training stack.

  • Dry run is the guaranteed path; it does not claim to reproduce paper benchmarks
  • Optional smoke inference with the lightest domain checkpoint from Hugging Face

PixelUMM

Kit for nv-tlabs PixelUMM, encoder-free unified image/video understanding and generation in pixel space (Qwen3-8B backbone). Targets the image-understanding task (--task image-vlm).

  • Code is Apache-2.0; the checkpoint is under the NVIDIA One-Way Noncommercial License
  • Full runs need a high-end NVIDIA GPU, CUDA 13 and the weights; guardrails are left on by default
