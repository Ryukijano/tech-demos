NanoDreamer on MinAtar

Clean-room reimplementation of ideas from Benjamin Bai's NanoDreamer (found via @benbye): a tiny Dreamer-style world model whose actor trains only in imagination. Upstream GitHub has no licence — no source was copied. Pre-registered CPU slice on Breakout + Space Invaders, 16k steps, seeds 0/1/2.

  • FAIL: Breakout mean 0.727±0.280 vs random 0.533±0.055 (misses every-seed + 2× bars); Space Invaders 0.937±1.207 vs random 2.700±0.295
  • ~460k params; actor updates are imagination-only; does not reproduce the upstream 500k-step MinAtar table
  • Breakpoints: <4k steps or a ~74k-param stack collapse on Breakout; horizon 5 beats horizon 1
cd apps/nanodreamer-minatar
uv venv .venv && source .venv/bin/activate
uv pip install --index-url https://download.pytorch.org/whl/cpu torch
uv pip install -r requirements.txt

Auditable SAE text detector

Official DetectorScope (arXiv:2610.30006, found via @_akhaliq): sparse autoencoder features with named descriptions drive an auditable AI-text detector. Pre-registered CPU slice on a CC-BY-4.0 human/AI essay set, seeds 0/1/2.

  • FAIL: τ=0.85 AUROC 0.824±0.031 stays ≥0.70 but lags τ=0.00 (0.982±0.006) by gap 0.159±0.030 — over the 0.05 bar on every seed
  • Decisions remain auditable (≈72 named active features/doc at τ=0.85); at τ=0.95 the head collapses to chance with zero features
  • Breakpoints: short truncations and top-k≤4 hurt; Gradio UI highlights top features for a pasted text

Binary Discrete Diffusion (Sudoku)

Independent re-implementation of arXiv:2610.28543 (found via @rodcasnog): denoise sets of candidate tokens per cell vs a matched masked discrete-diffusion baseline. No official code found — pre-registered CPU toy on synthetic 9×9 Sudoku, seeds 0/1/2.

  • FAIL: masked solve rate 0.688±0.042 vs binary 0.000±0.000 on 48 held-out 50-clue boards at NFE=32 (~111k matched params)
  • Binary still reaches ~0.79 cell accuracy but almost never a full valid board under the toy prune sampler — does not reproduce the paper's 43M Sudoku-Extreme result
  • Breakpoints: masked collapses as clues→30 or NFE→2; binary stays near zero. Prepared (unexecuted) Colab for a larger GPU run

Syndrome-mitigation QEC (VEC)

Independent re-implementation of arXiv:2610.12400 (Google Quantum AI, found via @zlatko_minev): reweight shots by MWPM-vs-exact-ML decoder disagreement sectors to cancel residual logical errors in post-processing. Pre-registered d=3/5 experiment at p=0.05, seeds 0/1/2.

  • VEC cuts residual logical bias 32–152× below plain MWPM and 15–101× below postselection on every seed; ⟨Z_L⟩ returns to 1.000±0.001 (ideal +1)
  • PARTIAL: overhead ratio η<4 holds at d=5 (2.4) and d=7 (1.73, near the paper's quoted weights) but not d=3 (5.4–5.7) — matching the paper's distance trend
  • Exact d=5/7 ML via transfer-matrix contraction verified against brute force; breakpoints: empty Y sector at p=0.01, threshold collapse, drift, 0.31%-error syndrome-only noise learning

Correction Training 2D toy

Pedagogical re-implementation of sunovivid/correction-training (arXiv:2610.14136): a stop-gradient corrector iteratively refines the denoiser's prediction at each sampling step. Pre-registered matched-NFE K sweep on 8 Gaussians, seeds 0/1/2.

  • K=0 baseline beats every K∈{1,2,4,8} on MMD² on all three seeds (0.84 vs 3.99 ×10³ at best K, seed 0) — the paper's ImageNet gain inverts on a near-optimal 2D denoiser with no exposure-bias gap to close
  • Breakpoints: ordering holds to K=64 and across NFE 6–240; the one flip is 4 well-separated modes, where K=2 wins. Trains in ~5 s/seed on CPU
  • MIT upstream; no checkpoints downloaded. Prepared (unexecuted) Colab for real SiT-REPA ImageNet sampling — GPU spend needs owner approval

LoMa local feature matcher

Demo of davnords/LoMa (arXiv:2604.04931): LightGlue-style matching with LoMa-B plus rotation-invariant LoMa-R. CPU clear-experiment with pre-registered latency, determinism and rotation breakpoints.

  • LoMa-B match latency about 8.3–8.7 s mean per upstream pair on 4 CPU threads, under the 30 s budget
  • Correspondence counts drift by a few matches across seeds 0/1/2 (strict identity fails). LoMa-R beats LoMa-B on inlier ratio at 45–90°, but not at every angle ≥ 45° (fails at 135°)
  • MIT code; matcher inherits Apache-2.0 from LightGlue. Weights auto-download; not committed
cd apps/loma-matcher
uv pip install -r requirements.txt
uv pip install "lomatch @ git+https://github.com/davnords/LoMa.git"

Active borylation

Demo of Minot et al., Nature Computational Science (2026) (ETH/Roche): active learning and geometric GNNs for Ir-catalysed C–H borylation. Shows the released EquiformerV2 checkpoint's per-atom regioselectivity on CPU, and a retrospective BALD vs random acquisition run.

  • EquiformerV2: top-1 site matches the product for 3/3 upstream examples (all three are also in its training set)
  • BALD vs random (XGBoost ensemble, 3 seeds): BALD needed more molecules to reach the target MCC, so the hypothesis failed
  • This app is GPL-3.0 (from minotm/active-drug-discovery); data CC-BY-4.0

Bone suppression for chest X-rays

Demo of Qure.ai's qureaiorg/bone-suppression (arXiv:2609.24937): two TorchScript models split a frontal chest X-ray into bone, soft tissue and lung component. It runs on CPU and includes a pre-registered stability test and breakpoint sweep.

  • Reproduces the authors' published outputs. CPU latency was about 10 s per 1024 px image for both models, under the 15 s budget
  • Stability under σ=0.01 noise: mean bone SSIM 0.942–0.945, just below the 0.95 bar. The decomposition breaks on inverted, JPEG q≤10, 64 px or high-contrast-clipped input
  • This app is CC BY-NC-SA 4.0 (weights' terms). Not a medical device and not for diagnosis
